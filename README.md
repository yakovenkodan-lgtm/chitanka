# Читанка — телефонна версія

Статичний вебзастосунок (PWA) для iPhone: читає книжки й аудіо з папки «Мій диск / Читанка» на Гугл Диску
власника, після входу через Google. У цьому репозиторії лише код — жодних книжок, аудіо чи особистих даних,
жодних паролів чи ключів (ідентифікатор клієнта Google — публічний за призначенням).

Іконки й банер малюють скрипти `.github/make_icons.py` і `.github/make_banner.py`, а коротка «тиша» лежить у `_bin/*.b64`;
дія `build-assets` створює з них файли `icons/`, `img/`, `audio/` і додає їх у репозиторій.
